# web-scraping-capstone
 Web scraping capstone project using Selenium, Pandas, and Streamlit

 # Weather Data Web Scraping Capstone

## Project Description

This project uses Selenium to scrape weather information from a public website.

The collected data is:

* Scraped using Selenium
* Stored in a CSV file
* Cleaned using Pandas
* Prepared for loading into a SQLite database
* Intended for visualization using Streamlit

## Files

* scrape_weather.py
* clean_weather.py
* weather_data_raw.csv
* weather_data_clean.csv

## Running the Project

Install dependencies:

pip install -r requirements.txt

Run scraper:

python scrape_weather.py

Run cleaning script:

python clean_weather.py
